# My MERN Stack Project

A full-stack web application built with MongoDB, Express.js, React, and Node.js.

## Features
* User Authentication
* RESTful API
* Responsive UI

## How to Run Locally

1. Clone the repository
2. Navigate to the backend folder and run `npm install`
3. Navigate to the frontend folder and run `npm install`
4. Create a `.env` file in the backend with your `MONGO_URI`
5. Start the backend: `npm run dev`
6. Start the frontend: `npm run dev`
